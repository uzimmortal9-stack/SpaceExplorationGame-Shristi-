# Asset Credits

Every external asset in *Aurora Drift* is **CC0 1.0 or public domain**, was
**actually downloaded and verified** by `npm run assets`, and is **self-hosted**
under `public/assets/` — nothing is hot-linked at runtime.

No texture in this project is generated by painting onto an HTML canvas.
Albedo, normal and roughness maps are downloaded image files; where a model's
shared atlas is unavailable from its mirror, it is given flat PBR colour values
(see [Palettised materials](#palettised-materials)), never a fabricated map.

Run `npm run assets` to reproduce the whole library from
[`tools/assets.json`](tools/assets.json), which records the exact source URL,
licence and destination for every file.

## Palettised materials

Some Quaternius packs (Ultimate Space Kit, Ultimate Stylized Nature) UV-map
every mesh into one shared colour atlas — a small image of flat swatches. The
public CC0 mirror carries the geometry but not those atlases, so the meshes
arrive with a single neutral base colour and no map.

Rather than ship grey foliage or invent a texture,
[`src/assets/palette.ts`](src/assets/palette.ts) assigns the flat colour the
atlas encodes, keyed off the material name the artist authored
(`NormalTree_Leaves`, `PalmTree_Trunk`, `Rocks`, `Flowers`, `Mushrooms`, …),
together with sensible roughness / metalness values. Any material that **does**
carry a real downloaded texture is left untouched, and if the genuine atlas is
later placed in `public/assets/kit/` it takes priority automatically.

## Conversion pipeline

`tools/usda_to_glb.py` is a from-scratch ASCII-USD → glTF 2.0 converter written
for this project (no external USD dependency). For each model it:

* parses `Xform` / `Mesh` / `GeomSubset` / `UsdPreviewSurface`;
* triangulates n-gons and de-duplicates vertices;
* resolves per-face material subsets into separate glTF primitives;
* honours indexed UV and normal primvars;
* converts Blender/USD Z-up to glTF Y-up;
* normalises the pivot to the model's bottom face, true centre, or leaves it
  authored, per the role declared in `tools/assets.json`;
* links shared atlases externally instead of embedding a copy per model
  (145 MB → 38 MB across the library);
* omits any texture reference whose source image is absent, so no model ever
  ships pointing at a missing file.

## Audio

All audio is **synthesised at runtime** with the Web Audio API — no samples are
downloaded. `src/core/audio.ts` builds pink-noise beds, filtered noise bursts
(door hydraulics, thrusters, footsteps, water, wind), FM tones (console blips,
target lock, alarms) and sustained detuned-oscillator drones (ship hum, reactor,
warp core). No third-party audio assets are used.

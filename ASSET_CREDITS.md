# Asset credits

AEON DRIFT intentionally uses no downloaded visual, model, texture, font, or audio assets.

- All geometry is generated at runtime from procedural primitives and custom buffer geometry.
- All materials and canvas textures are generated at runtime.
- All sound effects and ambient layers are synthesized at runtime with the Web Audio API.
- Star fields, planets, terrain, foliage, ruins, mist, spores, waterfall, holograms, and warp effects are procedural.
- Rendering uses [Three.js](https://threejs.org/) (MIT License).
- Build tooling uses [Vite](https://vite.dev/) and TypeScript (MIT Licenses).

The project title, lore text, ship design, interface, and procedural art are original to this repository.
